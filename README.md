# Welcome New Programmers

This README file will serve as a hub for important information and links designed to help you.

Before you start, please [install WPILib](https://docs.wpilib.org/en/stable/docs/zero-to-robot/step-2/wpilib-setup.html).
Make sure when installing to install `Everything` and not `Tools Only`. If you have a personal laptop and a desktop computer make sure to install on both devices as well.
